# Personal Expense Management System (tracker System)

🙋‍♀️ About
This project was created to demonstrate practical Python skills including:

- File handling
- OOP design
- Data analysis with pandas
- Data visualization
- CLI-based user interaction



📌 Features
  - ✅ Add daily income or expense entries with date, amount, category, and description
  - ✅ Automatically stores data in a CSV file (finance_data.csv)
  - ✅ Filter transactions between any two dates and view a summary
  - ✅ Generates daily-level plots of income vs expense using Matplotlib
  - ✅ Handles invalid input formats with proper validation

🧠 Tech Stack
- Python 3
- pandas – for data processing and filtering
- matplotlib – for plotting income vs expenses
- datetime – for date handling
- CSV – for persistent data storage
